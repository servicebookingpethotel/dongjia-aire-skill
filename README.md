# 東家國際地產 `@aire` 智慧商仲助理技能包

> 🏢 專為東家國際地產打造的 AI 商仲秘書與談判教練。  
> 內建雷蒙《speak-human-tw》繁體中文在地化與「去 AI 味」規範，支援電腦桌面版、網頁版與手機 App 全端共用。

---

## ⚡ 快速安裝教學

### 方式 1：Codex / ChatGPT 桌面版（新增市集）
1. 打開 Codex 或 ChatGPT 桌面版。
2. 進入 **外掛程式 (Plugins) ➡️ 新增 (Add) ➡️ 新增外掛市集**。
3. 填寫以下欄位：
   * **來源**：`https://github.com/servicebookingpethotel/dongjia-aire-skill`
   * **Git 參照**：`main`
   * **稀疏路徑**：（**留空，不用填**）
4. 點擊 **「新增市集」** 即可完成安裝！

### 方式 2：Google Gemini（上傳技能）
1. 打開 Gemini 電腦網頁版，進入 **技能 (Skills)** 頁面。
2. 點擊 **建立 ➡️ 上傳**，選取本專案的 `SKILL.md`。
3. 儲存後，手機與電腦 Gemini 自動同步！

### 方式 3：Google Antigravity
1. 在專案的 `Customizations` 頁面填入本儲存庫網址即可加載。

## 🚀 如何使用？

在任何對話框中輸入以下指令即可啟動：

```
/aire
```
或直接在對話中提及 `@aire`、`東家`、`找房`、`商辦`。

### 啟動後歡迎導引
啟動後 AI 將主動顯示任務選單：
1. **【客戶需求訪談】**：輸入客戶基本背景，生成收斂的「三步提問法」。
2. **【坪數與租金試算】**：自動拆算公設比、扣車位坪數單價與免租裝潢期。
3. **【物件說服話術生成】**：依科技業、生技、電商量身定制現場說服文案與抗性化解話術。
4. **【物件庫存檢索】**：快速檢索符合條件之商辦/廠辦/店面。
